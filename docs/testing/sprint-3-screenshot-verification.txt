METHOD
------
Each screenshot was captured from the running browser with the session's
screenshot facility, which returns a content-addressed PNG on the host disk.
That file was then copied, byte for byte, to BOTH locations. No image was
generated, redrawn, edited or reconstructed.

Each file was then verified by:
  1. existence on disk;
  2. byte size greater than zero;
  3. PNG signature (89 50 4E 47 0D 0A 1A 0A) at the start;
  4. IEND chunk present at the end (catches truncation);
  5. SHA-256 of the desktop copy compared with the project copy.
