      date instead of raising ValueError.

    - can_complete_registration(): returns (False, <message>) when the member's

      member once.

      unreadable date, so it never raises.
    - guardian_linked_members(): reports age = None instead of raising.
    - Removed the now-unused "from datetime import date" import.
    - Reason: defect S3-D1.

      when the stored date cannot be read, instead of raising.
    - Reason: defect S3-D1.

      the age is unavailable, instead of rendering an empty age.
